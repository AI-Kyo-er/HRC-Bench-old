# 接触历史、空间动作与机器人活动学习

Material Passport：run／validate；用户Goal授权，无模型／数据下载。上一轮真实动作学习完成，独立两物品成功但共同活动失败；其精简输入没有直接手／机器人接触提示。本轮同时改善观察、开放空间动作和扩大数据，不能作单因素改善归因。

InteractiveArticulatedHuman在同一次实际模型生成中自由选择个人目标、现有动作与move_hand目标xyz。当前真实手部接触／其他主体接触、两次过去测量、当前身体和手部目标保留；它们是测量，不是成绩。move_hand仅通过现有受力控制移动手部并保留夹指压力，不抓放、不自动选择后续任务。工作空间参数约束不选择策略。正式Benchmark不调用数据教师。

数据教师仅用于data generation：8条pi05活动轨迹（food／炉面×init0／3×两顺序），4条机器人泊车餐盘／酒瓶轨迹。每条80秒20Hz，真实三机位20fps；机器人活动由真实π0.5每10步推理原生7维OSC，物品pose写入0。根据实际接触或连续无进展示范手部退开／抬高，再重新观察和操作；没有将教师算作NN伙伴成绩。

新数据独立核查：活动炉面4条完成两物品并通过运动，其余food4条仍受阻；餐盘4条中有1条目标成立但物体峰速1.57m/s超1.5阈值，其余未完成全部目标。只把4条完整合格轨迹用于监督，8条保留诊断，不把反复重试当成功专家数据。

与原16条有效静止机器人范例合并，原始输入／标签总960对，监督640对（train440、dev200），20条合格episode。原始接触与过去两次真实测量从raw trace重建v2输入，标签不改；同stem.source.json／.target.json，episode在__step之前归组，无配对manifest。所有init3整个episode为dev；新初始化用于闭环，避免随机拆帧。新增接触恢复实际数据仍只涵盖少量状态，不能声称全面泛化。

单卡GPU0 BF16 Qwen3-14B LoRA，基础权重冻结，q_proj／v_proj rank8 alpha16，200固定优化步、batch1累积4、4096tokens、seed41。样本最长3627tokens不截断。权重共享models，数据／结果／缓存data1。每40步权重仅阶段保存，最终配置不根据闭环结果择优改写。
