# 接触历史与机器人活动的学习实测

[打开报告：三场模型评测和12段数据生成真实Sim视频](index.html)。本轮已完成，成熟Dynamic Human Policy HRC Benchmark仍未完成。

此前学习伙伴曾独立完成碗与酒瓶整理，但共同活动失败，且精简输入遗漏直接手／机械臂接触。本轮同时补充当前接触和过去两次真实测量、开放保持夹持的手部空间动作move_hand、增加机器人实际活动中的训练范例，检查这些改动能否形成可靠闭环操作与共同完成。三因素一起变化，不能作单因素改善归因。

机器人为已有实际π0.5权重，每10个20Hz控制步重新读取两路实时图像、机械臂状态和原任务语言，输出7维OSC动作。task_only输入没有附加人的私人目标或协商消息。人是实际Qwen3-14B＋本轮LoRA，每2秒一次thinking推理，同时自选个人目标和下一动作；没有教师接管、固定目标路由或计划队列。人读取理想几何和真实接触，双指代理通过力控抓放，没有物体位置写入或吸附。骨骼人体显示、双指代理并不等于完整人体／五指模型或真人心理效度。

新增12条80秒教师轨迹：8条真实π0.5活动、4条机器人泊车下的餐盘／酒瓶。只有炉面场景4条完成两物品且运动合格；入碗4条受阻，餐盘4条中1条目标成立但物品峰速1.5704m/s超过1.5阈值，均保留诊断。与原16条有效静止机器人范例合并：20条合格episode，640对监督（训练440、验证200）；原始960对均保留。按同stem匹配，init3整episode为验证，init4测试，不用配对manifest。所有新增12段完整视频核验通过；教师成功不计学习模型成绩。

训练使用本地中国源Qwen3-14B、BF16单卡GPU0、rank8／alpha16／dropout0.05、q_proj／v_proj、学习率0.0001、累积4、4096token、seed41，固定200优化步。实际更新5,242,880个参数，变化范数6.5624，基础权重冻结、运行期间源码变化0。验证回答损失1.2201→0.001505。损失下降不等于闭环能力提高；新增有效恢复样本覆盖仍很窄。

三场测试均init4／seed4、完整60秒，实际人模型各30次调用。独立资格前有4秒真实机器人泊车，之后机器人NN调用0；两共同活动各120次π0.5推理、1200个实际控制动作。完整视频、模型输入／原始推理、实际控制、接触、状态及逐帧时间轴保存。

| 条件 | 人实际行为与期末结果 | 机器人与共同活动 |
|---|---|---|
| 独立操作资格，碗／酒瓶 | 碗16.45秒首次释放稳定，期末成立；随后观察，酒瓶未完成，整体失败 | 机器人无任务，不计HRC |
| 奶酪入碗共同活动 | 30次grasp酒瓶，没有实际抓放完成；手／机械臂接触累计57.35秒，人整体失败 | 机器人期末任务成立，共同满足0秒 |
| 碗放炉面共同活动 | 先grasp餐盘，后重复grasp奶酪；无实际抓放完成，人整体失败；手／机械臂接触1.20秒 | 机器人期末任务成立，共同满足0秒 |

三场每次决策均保留直接接触测量（30/30）；从原始接触重建、过去两次测量历史与实际NN请求核查通过。全部没有选择move_hand，没有自主目标集合变化；开放空间动作尚未形成实际模型恢复能力。运动／人物显示核查均合格，物体pose写入0，旧缓存place完成后重启见证0。核查通过只证明记录、执行和测量一致，不能替代协作效果。

稳定目标按实际物理轨迹、真实接触与释放后支撑关系核查，机器人任务持续成立与共同满足时间独立保存。不能把模型说“已放好”、目标文字变化、单方成功或视频核验绿灯称为cobalance。由于输入、动作和学习数据共同改变，本轮结果没有证明比上一轮改善；也不足以推断所有具身模型的能力边界。

重要实验必须先核验非空视频、逐帧解码、FPS、帧数及轨迹起止覆盖，再发布正式HTML。本报告将模型闭环视频放在数据教师视频前；支持播放、拖动以及同步显示自选目标、当前动作、空间位置、当次接触和模型解释，完整保留等待、受阻和失败。轨迹为辅助审计，不替代运行时真实Sim画面。

本轮仍未形成可靠神经伙伴。完整Benchmark还需要更广有效交互训练分布、多任务／初始化的公平统计、实际动态需求与目标重组覆盖、完整人体以及cobalance构念效度。当前这些条件不能以新提示版本或工程资格代替。
