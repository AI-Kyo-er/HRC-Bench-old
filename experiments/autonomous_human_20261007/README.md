# 个人偏好驱动的自选目标：两种具身模型实测

[打开报告](index.html)。本轮去掉固定的人工作分配和定时任务变化；由真实Qwen3-14B选择自己的长期意图、可观察目标、计划、当前动作和公开协商提案。

## Material Passport

- 模式run；材料为真实MuJoCo运行、π0.5/OpenVLA推理、人模型原始输入输出和Sim视频。
- 运行来源为提交4a7bfe6的冻结代码、本地中国源离线权重与已有场景/人物资产。

## 与上一轮的区别

上一轮人在0/15/30秒收到预定搬运要求。这次只有初始场景背景和机器人的公开工作，没有人类物体任务、定时工作更新或强制目标改变。
人的个人背景只进入自身模型：

- snack_host：自己准备点心桌，希望食物易取，完成个人整理后可选择是否协助机械臂。
- workspace_owner：维护共用桌面的秩序和个人物品取用，根据对方实际动作提出安排、保留原位或离返。

二者均为independent稳定倾向，不能根据两个背景推断真实人格效度。两个背景也不是预设的动作策略。
参考[COOPERA官方人类仿真](https://github.com/dannymcy/coopera_code/blob/main/HUMAN.md)及本地PDF中偏好、意图和环境驱动的建模方向；本实现是单个本地生成式策略同时产生意图、目标和当前动作，不宣称复现其整日活动、心理特征校准或多阶段Reflexion。

## 人的自主策略与公开边界

人每2秒观察物体、区域、手和身体执行反馈、机器人可见运动、自己的旧意图/经历，以及公开话语。
模型写出最多3个personal_targets对象/区域关系，可维持、修订、放弃；当前动作可与长期计划不同。
程序只校验对象/区域存在以及JSON接口，不依据完成分数替人选择动作；plan不自动执行。
合法目标被保留为模型自身意图，缺字段/无效目标提供接口反馈并保留此前目标；合法动作仍独立执行。
可发request_space/request_help/offer_help/revise_arrangement提案，程序只公开传递，不替机器人接受或改变分工。

π0.5/OpenVLA只获得公开机器人任务、自己的图像/本体接口和最近公开人类话语。
不将人的个人偏好、personal_targets、目标是否完成或评测器坐标直接注入机器人。
π0.5用外部+腕部相机、8维本体状态，最多执行10步；OpenVLA实际只消费外部相机+语言、每次一步，严格沿官方LIBERO图像预处理。
两者都是原生7维OSC增量/夹爪命令，没有教师接管或物体吸附。
这两种原生动作模型没有语言回复通道，协商仅是人提出、机器人以动作回应；不能称双方达成了协议。

## 世界与物理

每模型×每背景一条45秒运行，task2/init0/seed0、20Hz；世界与人策略各初始化一次，保留动作状态、意图和经验。
只绘制初始绿色/蓝色盘区域及橙色/紫色饼干区域，不改物体位置。人可选择任意当前可见对象与区域，不限制成推盘单任务。
动作是限速受力指尖及连续离返，人体皮肤仍是非碰撞运动学显示，未实现完整手部抓持与人体动力学。
生成推理期间模拟时钟暂停，45秒是模拟时间，不是实时延迟。
固定运行窗口不因一度成功结束，原始任务控制器可能再抓取已放物体；报告将首次成功与最终维持分开，不把这种闭环配置等同原始模型官方成绩。

## 测量

可观察目标集合变化按物体/目标区域的几何关系判定，文字改写与区域别名不算新目标。
每个目标区间记录初始距目标、选择时是否已在区域、首个持续稳定关系时刻、期末关系、实际接触与位移。
25mm目标范围、高度误差25mm、速度低于0.08m/s持续0.2秒，仅属于可观察物体关系；不能证明主观满意或因果贡献。
已经满足的目标不计作新完成贡献；撤销后的历史达成不算当前目标满足。
无可观察物体目标时标记不可评，不能把休息等主观意图记成全部物体任务完成。
机器人按原生几何、碗盘接触、夹爪释放和稳定判定；首次达成和最终维持分开。
公开提案数量与实际进入机器人输入的次数记录，不把消息数量当理解、协商成功或cobalance分数。

这批只有两个背景/一个倾向/一个布局。两种算法各自保持采样状态，人会随各自实际轨迹变化；这不是固定人轨迹配对，也没有统计排名或因果控制。
