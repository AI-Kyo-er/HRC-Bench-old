## 本轮改变的核心

人的动作输入保留当前真实位置、接触、握持、公开分工、私人意图与最近实际状态。
过去生成的memory_note和行动解释不作为动作事实反复输入；公开交流与承诺仍保留，不能因为删除旧解释而遗忘真实分工。
意图推理启用本地Qwen3的推理模式；完整原始输出和最终JSON分别存储，未完成推理不当作最终决定。
动作选择仍由模型完成，不按plan队列执行，不按任务成绩路由。

私人目标允许合法on:接收物体关系，跟随接收物当前状态；基于原生On近似几何定义再检查接触、双方手部释放、速度和稳定。
不会以初始bowl_home坐标替代当前接收关系，亦不把on解释为完整容器包含。
本批三基础运行没有选择相对目标作为私人意图，不能将接口扩展称为已验证关系目标规划能力。

## 三基础运行的实际结果

配置：independent、episode、init0／seed0、60秒／20Hz。goal task1／0为炉面／抽屉，spatial task2为共同上桌。
人模型每6秒反思、每2秒选择一个动作；π最多10步原生OSC块，世界／策略各初始化一次，推理时模拟时钟暂停。
不附加固定人动作清单或定时目标改变。

- 炉面场景：人选择自己的plate_1，最终仍未抓起／整理完成。人掌部与机械臂link6／7存在接触记录，累计56.35秒，下降目标与实际位置相差明显。
- 共同上桌：人先观察等待、随后尝试移动餐盘，最终未满足私人关系；人手／机械臂接触记录16.15秒。
- 抽屉场景：人尝试wine_bottle_1，并自主yield／重新尝试；11.85秒出现双指接触及抬高见证，未完成目的地放置。
  18秒移除plate目标、42秒恢复，语义变化2次；这是优先事项集合变化，不是物理成功或真实心理效度证明。
  机械臂期末抽屉目标成立，私人目标未满足；接触记录11.10秒。

三例私人目标及双方当前目标均未完成。人的选择开始对应自己的物品，并有自主优先事项变化，但不等于有效共同活动已经成立。
私人目标、接触证据、动作声明和实际放置必须分开。

## 后续双向运行

仍是碗放炉面＋个人整理的60秒活动。人的输入新增自身手部真实接触几何、实际速度和电机命令；电机命令不是接触力估计。
机器人以Qwen3-VL-8B读取开始／当前外部和腕相机、自身本体／执行记录／接触、公开任务和对话，自己选择execute或hold并可回应。
execute用真实π运动模型；hold为模型选择的姿态保持原语，分别记录，不把保持伪装为学习VLA运动。
双方都不读私有评分，人私人目标不自动传给机器人。公开回应不自动成为协议接受或任务重分配。
两批感知与机器人策略不同，未严格配对，不能做因果或算法排名。

## 核验与数据约束

广角／原始外部／腕相机同一时刻录制，896×512／20fps；不是轨迹动画或补画视频。
模型输入与输出、实际原生控制、20Hz时钟、两阶段目标来源、公共／私有边界、真实几何／运动与骨骼显示分别核查。
几何接触审计只计人手与robot/gripper且distance<=0；不证明接触力、伤害、完整人体碰撞或唯一阻挡原因。
三基础场景的手／机械臂接触清单未直接给人模型；后续加入的感知不能用于重写原三条输入或把改进归给某单项模块。
强制视频／时间轴核验再生成正式报告，原始失败保留。

原始运动动作可按同stem导出，校准教师不混入，完整episode隔离，不生成配对manifest；失败不是专家示范。
带模型保持原语的双向轨迹与纯VLA运动分开，其原始来源标签和视觉决定保留，不能把两类动作混作同一运动监督。
