# 测试初始化的操作可执行性参考

预先固定：三个活动snack_service、drink_storage、drawer_access，各初始化4与5，共六条，每条120模拟秒、seed65。使用固定人参考、原生任务语言、初始持物和真实π0.5原生操作。六条全部保留，包括失败；不根据结果挑选初态，不用本批修订动态人提示或拟合其策略。

目的：在正式多系统评测前确认计划测试初态下的基本操作及贡献链是否可执行，区分原生操作困难与动态协调困难。人NN为零，无动态情境。此批不作为动态人策略成绩，也不计入正式72例样本；已看过的可执行性结果不能称完全未触碰的测试数据。正式分割和冻结状态另列。

参考边界：被提供对象后，抓取／放置或开抽屉的动作来自实际π0.5。人提供与接收阶段由固定参考安排；机器人等待和贡献完成后的清场使用明确记录的reference_scheduler_hold与reference_clearance_cartesian。因此不能将整段机器人轨迹说成全部来自VLA，或将参考调度能力归功给模型。此批仅验证当前参考链，不验证九条技能在所有动态状态下成功。

完成要求：每条保存完整Sim视频、逐帧时间轴、观测、实际动作及来源；终态后独立核验输入和控制、解码视频、审阅reference_complete与实际终态。所有六条终态与失败分布均发布，未结束的运行只列待回收。
