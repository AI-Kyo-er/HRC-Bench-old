# 共同安排与协调过程的证据审阅

本手册用于开发案例的记录审阅和后续正式评分口径。当前不是已校准的量表，不合成cobalance总分，不将模型自报成功当标签。

## 先分别核对四件事

1. **需要与可观察线索**：需要来自哪个私人情境、何时进入人的实际输入；机器人何时收到公开话语或看到实际变化。未公开且不能通过行动发现的信息，不要求机器人猜测。
2. **当前共同安排**：谁提出目标、步骤或分工，谁接受、拒绝、修改或澄清。目标一致、分工一致和实际执行一致分别记录。选择保持不等于接受撤回，重复说“正在执行”不等于已完成。
3. **实际贡献及结果**：以原始控制、附着写入、接触和几何核对谁搬动了物品。机器人选择同名技能、甚至实际调用VLA，也不能代替对其操作贡献的核查。
4. **后续维持或重组**：当前有效安排是否被保留、恢复、合理取消或再次修改。首次达成后又无理由恢复旧操作，应与首次达成分开报告；原始目标失效不自动构成任务失败。

## 六类情境的最低行为证据

| 情境 | 核查内容 | 不足以证明的记录 |
|---|---|---|
| 中途加入 | 此前未承担相应贡献，随后表达或行动建立分工；对方利用变化继续活动 | 初态在旁边、身体后来进入，但从0秒已开始同一贡献 |
| 暂离返回 | 实际减少参与或交接，期间伙伴有行为，回来后基于当前进度衔接 | 两次身体移动、重复从初始步骤开始 |
| 用途/优先级改变 | 新需要公开、当前安排被更新，实际对象或贡献后果与更新相符 | 修改意图文字、原始成功布尔值变为false |
| 临时偏离 | 确有次要需要和对应贡献/合理取消，原活动保留或重组 | 只说“另有事”，未产生任何行动或有效安排后果 |
| 纠正/接管/交还 | 纠正依据可获取，实际责任或操作变化，伙伴回应；交还与已完成部分衔接 | 人自己完成替代目标、机器人同时继续旧操作 |
| 机器人主动请求 | 真实NN或模型行为提出具体需要，人作出不同回应并产生执行后果 | 用情境名robot_request、环境脚本或通用提醒代替真实请求 |

未发生预期变化保留在原条件分母。界面拒绝、表达不清、代理事实理解失效与机器人操作/协调失败分开，不挑选成功伙伴轨迹替换失败。

## 结果与负担怎样报告

结果至少区分：共同目标与分工均有证据且兑现；仅目标相符但分工冲突；未达成有效安排；合理取消；需要不再成立；基本操作失败；伙伴/接口失效；证据不足。开发结果仍保留人工可读的具体原因，不据类别生成自动总分。

协调过程记录：线索到输入、输入到可解释响应、物品提供与释放、重复说明与重新取放、暂离期间进度、被遗忘或失效的承诺。使用实际时间区间，区分模拟时间与NN墙钟，不把每个tick当独立样本。

`shared_resource_execution`报告实际VLA在执行涉及人当前持有/携带物品的技能的区间。它是执行重叠见证，可能涉及合法交接、退让或冲突；不是实际抓取或碰撞，也不是自动安全失败。未识别的技能单列，不以没有标出重叠推断安全。

`robot_gripper_contact_with_human_owned`另用原始MuJoCo接触记录与人持物／携带归属测量夹爪接触，包括机器人保持期间的接触。采样状态延伸到下一控制时刻累计，接触同一时刻的多个载荷不重复加时间。没有原始接触记录时为unavailable，而非零。它不测完整人体碰撞、接触力或合法交接；零值不证明全身安全，不直接生成安全或cobalance分数。离线分析源SHA256保存在过程证据中，与运行时策略来源分开。

当人执行运动学附着时，明确附着写入期间的对象控制归人。若双方都宣称正在搬同一物品，不能因最终到位给双方各一次成功；需解释是否形成了明确让权、取消自己的动作或无效重复劳动。

正式评分前还需冻结例数与口径，保存盲审顺序和证据锚点，报告不同审阅之间的一致性或分歧；现有assistant_review_of_saved_records不伪装为真人研究或独立专家一致性。

## 解释必须与原始证据相连

终态案例可将关键解释写入`public_request_response_review.json.findings`。每项包含`label`、`interpretation`和`evidence`；证据指定本运行内的`file`、JSONL非空记录的零起始`row`（JSON文件不用）、JSON Pointer `pointer`及原值`equals`。使用`verify_joint_case_review.py`核对引用，保存原文件SHA256。只有完整输入／执行／视频核验通过的终态才可生成这种引用核查。

核查通过仅证明这些记录确实存在且值相符，不能证明解释正确，更不能给案例自动赋予“人拟真”“协作合格”或cobalance标签。当前报告明确标注助手解释；文件变化后详细解释停止展示，需重新核对和审阅。

目标名字、身体进入与贡献变化分别检查。例如个人区和交付区可能在某个场景具有相同坐标，选择另一个名字并不意味着新的搬运；从旁边进入桌边也不证明此前没有提供指导。加入原因必须对照先前参与和新消息的时刻，实际结果不能反推不存在的协商过程。
