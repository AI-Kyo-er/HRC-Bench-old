# 视觉原生技能协调系统的开发协议

Material Passport：run；在启动前记录，非正式排名样本。

第二系统为 Qwen3-VL-8B 视觉协调＋实际 π0.5。它读取初始／当前外部相机、当前腕部相机、自身传感器和实际控制历史、公开任务及公开交流；没有场景真值坐标、人的私人背景或意图，也没有任务评分。原来的视觉协调开发允许直接末端移动，产生大量没有调用 VLA 的结果；新系统只提供 execute / hold 两种工具，实际操作必须交给 VLA。

available_vla_operation 取自请求已公开的原生任务第一行，后续部分是共同活动说明。高层 NN 自己决定何时 execute / hold，适配器仅将所选 execute 编码为模型支持的原生操作，不读取任务分数或按阶段路由。生成的原始指令和编码后的实际指令分别保存。该系统不是自由动作语言或新技能生成器，也不是裸 VLA。

首条为点心 / busy / leave_return，init1 / seed62 / 120 秒，两主体每4秒决策、人候选＋反思，初始人持碗，策略字段 schema2；与同批理想感知条件使用相同任务、人物背景和情境采样。伙伴随后可以因机器人的不同实际表现产生不同回应。

比较边界：两系统同时改变高层模型和感知接口，不能把差异单独归因为视觉或协调模块。先分析渠道、模型实际调用与行为；不凭一例排名，也不把无效伙伴条件纳入正式成绩。可靠伙伴和六类实测覆盖后，再冻结正式多任务、多初始化评测矩阵。

视觉模型约16GB权重加8GB运行预算，使用GPU1；人模型约28GB权重加8GB预算，使用GPU3剩余显存，已运行的π0.5约9GB。各程序仍只使用一张已检查的足够显存卡。运行前重新检查显存；若预算不足，等待已有worker释放，不降低实验条件冒充已运行。
