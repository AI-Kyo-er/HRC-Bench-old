# init2 原生操作参考

在三条技能库开发运行之外，顺序运行点心、饮品和抽屉三类固定人参考。初态init2 / seed63 / 初始人持物 / 120秒与新批一致，人高层决策0NN；参考调度在实际准备完后调用真实π0.5，不用记录轨迹反馈或机器人吸附。

用途：检验本初态原始操作能否完成，并为基础操作／协调失败区分提供证据。它只约束参考调度，不将该调度混入正式人策略或机器人协调系统，也不按参考动作自动矫正被测系统。

三类结果无论成败都保留并核查完整视频。此批不证明九条可选技能全部成功；根据实际使用的新技能还须补充相应操作验证。参考成功也不自动证明同初态的神经条件失败源于协调，因为人动作／观测过程和时序仍可能不同。
