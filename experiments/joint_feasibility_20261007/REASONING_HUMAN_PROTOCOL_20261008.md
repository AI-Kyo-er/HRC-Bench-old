# 人策略原生推理模式的资格检查

已有不思考条件即使获得语义事实仍出现将未填碗称为填好、将已打开抽屉称为不可进入等不一致，说明可靠模拟伙伴尚未验证。先检查现有Qwen3-14B原生thinking能力，不训练抓放模型、不增加教师策略或评分。

新抽屉条件init3 / seed64 / busy / robot_request / 120秒，视觉Qwen3-VL-8B＋实际π0.5原生技能库，人相同语义观测、贡献参数域、连续暂放执行。人每4秒单次原生推理，最大4096新token，没有候选＋反思第二次调用；机器人模式不变。记录完整原始think与最终JSON，动作仅取模型最终选择，输出不完整时保留失败，不能后台给出正确动作。

这是人策略有效性的组件资格检查，不是第三个机器人模型，也不作为严格单因素提升。计算预算与输入/执行契约均披露，报告推理墙钟和模拟时间。若仅思考文本更长却未改变实际行为或仍违反事实，不算可靠伙伴。

重要实验提供完整真实Sim视频与独立输入／控制／时间轴核查；验证同一NN可依据当前测量、伙伴表现、自己的需要，生成合理的参与或贡献选择。模型可以拒绝或保持，不能强迫每episode角色切换。六类覆盖和正式72矩阵仍未完成。
