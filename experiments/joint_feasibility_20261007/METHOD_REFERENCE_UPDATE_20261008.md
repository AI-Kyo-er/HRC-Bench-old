# 本轮方法核对与采用边界

重新核对原论文与本地官方实现；本项目是自主构建的Benchmark，不复现论文全部流程。

HABIT用人／机器人子任务及跨主体顺序边组织工作流，并要求行动依据记录中可观察的伙伴线索发生；其评测区分操作、工作流合规和安全。它还明确以匹配的Robot-only数据条件比较训练影响。本项目采用依赖与观测可达性审计，持续活动中的约定允许双方改变，不用后台强制执行整条预定工作流。现有LIBERO权重不是HABIT适配权重，不能用其失败代表所有π0.5的HRC能力。[HABIT原论文 §2.1、§2.3、§3、§4.1](https://arxiv.org/html/2606.31682v1)

COOPERA将人物背景、意图／任务历史和环境结合生成活动，采用分阶段生成、检索与反思，并独立评价人物多样性和时间依赖。本项目已采用背景、实际测量、私有情境、互动历史及候选＋反思；尚未复现其人物扩展、心理量表或整日评测，也没有据此获得真人拟真验证。这里的实时动作／消息反馈是本项目的实现选择。[COOPERA原论文 §3.2、§4.2](https://arxiv.org/html/2510.23495v1)

本地pi05-libero的train_config记录LIBERO数据路径和LIBERO适配权重名称；不包含本项目HRC训练。本轮没有新模型或数据下载。九条公开操作核对安装的原生任务语言，但实际操作可靠性、人物策略效度和正式样本评测仍需完成。

新运行已显示抽屉的人反复请求搬奶酪，却因仍持有餐盘而被单手执行器拒绝。该问题属于人执行抽象的限制，不能算机器人的协调失败。待当前冻结运行结束后，应使所选人贡献可以可靠兑现，例如在明确标注的低层执行中连续暂放原持物，再执行已选贡献；不得由此代替人决定下一任务或将暂放记作NN新策略。
