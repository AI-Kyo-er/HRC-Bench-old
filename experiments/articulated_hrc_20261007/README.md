## 操作和场景

接触手由实际关节motor驱动，指垫/掌有碰撞与摩擦，不绑定、焊接或搬写物体坐标。
抓取原语估计碰撞几何的较窄夹持方向与所需初始指距，限速接近、下降、闭合、触觉确认、抬升。
只有双指接触且物体实际抬高，才报告测得在手中；place由模型明确选择，搬运/下降/开指/清离不是生成计划自动路由。
observe保持实际手位和夹指，目标和下一个动作仍由生成模型决定。无测得抓持时place被拒绝，不因文字声称已经拿到而接受。
受力手引入更大的有效惯性和限速速度跟踪，不直接夹断或改写qvel；没有放宽0.65m/s速度及25mm对齐门槛。

实际木色收纳台在桌面上高8cm，gold区域对应其支撑面；cookie/plate目标按各自初始支撑高度定义。
高台布置避开初始盘/碗，水平推物无法直接把物体送到高台顶面。
主体仍是VICO完整皮肤/骨骼显示，不是完整人体碰撞动力学；双指是物理抓持代理，不是经真人验证的五指灵巧手。

两个正式背景：
- snack_storage：人希望把自己的饼干存到靠近自己的高台，腾出共用桌面空间。
- shared_serving：人希望餐盘最终在高台上，可整理食物，也可等机械臂放碗后移盘；具体时机由模型看实际状态选择。

机器人仍公开负责原生黑碗放盘；人自主目标私有，只有它公开说出的消息/提案进入机器人语言。
不存在定时人任务更新，也不由评分器决定抓哪个或何时放置。
每条40秒/20Hz，Qwen每2秒推理，π0.5最多10步；世界/人策略各初始化一次。两场景GPU0/1、模型服务GPU3，每程序单卡。
共用π服务的采样状态可能随推理请求顺序改变，本批不作条件间因果排名。推理期间模拟时钟暂停。

## 独立物理校准

第一条校准发现高台初始位置与盘重叠、张手过宽下降受邻物阻挡，物体没有抬起；保留为诊断。
修订几何布局和按实际碰撞尺寸开指后的正式校准完成真实抓放：7.25s双指接触抬起，13.15s释放接触高台，
最大物体抬升12.43cm，手峰速0.196m/s、物体采样峰速0.197m/s，显示资格通过。
没有把校准教师或机器人原地控制计作生成式人、学习模型或HRC成绩。
