## 目的与设置

此前流程在意图更新后仍可能向动作模型提供按旧目标计算的几何。本轮重建当次目标几何、明确自己的当前目标与双方身份，并将过去生成的观察判断从动作事实输入中移除。人的目标与动作依然由Qwen3-14B自主生成，没有外部动作清单、定时目标切换或任务分数路由。

人每6秒进行长期意图推理、每2秒选择当前动作，意图采用thinking模式2048token、动作非thinking模式512token。每场10次意图、30次动作推理。机械臂共同活动采用实际π0.5-LIBERO双相机、本体状态和语言输入，120次推理生成1200个7维原生动作，20Hz持续60秒，一次初始化、init0／seed0。人是理想几何感知的生成式伙伴，动作由双指受力代理执行，人物为骨骼显示；没有运动学吸附或物体pose写入，但尚非完整人体及五指动力学。

## 实际行为

| 场景 | 实际行为 | 结果与限制 |
|---|---|---|
| 自主操作资格 | 人选择碗和酒瓶，碗16.40秒首次满足释放稳定个人区域关系，之后反复抓放；酒瓶无人接触 | 人期末目标未完成；运动资格通过；机器人模型调用0，不计HRC成绩 |
| 奶酪入碗共同活动 | 人的目标为碗和酒瓶，却30次抓取奶酪，未操作自己所选目标 | 机器人严格关系累计53.90秒、4次失效、期末成立；人失败、共同满足0；运动资格通过 |
| 抽屉访问共同活动 | 人持续抓放自己的酒瓶，没有形成个人区域关系，也未操作第二目标餐盘 | 机器人任务累计37.40秒、期末成立；人失败、共同满足0；物体峰速1.596m/s超过1.5m/s阈值，保留诊断 |

操作当前个人目标对象的动作数量：资格29次、奶酪0次、抽屉28次。奶酪30次操作其他可见物品；这可能是帮助、准备或角色混淆，类别本身不自动判错，需要结合原始解释与实际效果判断。

## 证据与数据

逐场独立核查真实模型像素／状态／原生动作／实际控制／物理时钟、目标及私有边界、实际握持反馈、相对支撑几何、场景完整性、人物显示、运动及视频。验证器不参与策略决策。全部原始输入输出与失败证据保留，报告可直接访问。

两共同活动导出240组双相机观测、2400个原生学习动作：[数据说明](../../datasets/current_intentions_20261007/README.md)。120组运动合格、120组诊断；独立按stem加载所有样本，各1200有效动作。资格场景没有学习机器人动作，不混入VLA数据。数据是实测失败也保留的行为记录，不是专家示范，不以manifest表达配对。

本批使用冻结的`current_intentions_and_measured_geometry_v2`输入契约，运行中源文件变化均为空。收尾只读审查发现相对目标高度取了接收物body位置，后续`current_intentions_and_support_geometry_v3`改为当次碰撞支撑面；新增接收物移动、支撑高度与body不同、旧v2记录兼容的回归测试。三场实际目标都是固定区域，因此该修补没有在本批真实相对目标行为中复测，也不回写原始结果。

## 结论及后续工作

修正输入一致性并未得到可靠自主伙伴：机器人泊车时仍反复操作第一件物品，共同活动中还出现目标与操作对象不一致。行为失败不能仅归因于VLA权重，也不能用单方任务成功说明HRC。前后不是严格随机配对，不能据此做单因子因果结论或模型排名。

下一阶段核心是让生成式伙伴可靠完成多物品活动，并产生真正的目标变化与接收物操作；需要以行为证据评估人策略、动作接口和模型学习，避免继续围绕提示微版本或打分路由迭代。完整人体、五指、动态容器、多人效度、跨任务统计评测和cobalance研究效度均仍待完成。
