# 实际执行反馈与生成意图分离

[打开报告](index.html)。本轮修正三类结构问题，不根据任务分数给模型选动作：

- 视觉协调器的`self_execution`独立记录实际控制步数、VLA/保持块、上一条动作、
  末端位移、夹爪关节位置与接触采样。生成的history/plan仍是模型自己的解释。
- hold沿用上一条实际夹爪命令，避免把较宽物体的夹持间距误解为应该打开；
  没有上一动作时才使用初始开度。EE零增量是保持原语，单独计数。
- 人的目标到达后只有限退手一次，重复push不再把手越抬越高。
  observe仍保留最后操作物体的几何距离和可见区域范围，供模型重新判断。

位置、控制次数、接触不是私有任务完成标签，也不认定抓取成功。
模型仍自主选择execute/hold、推/看/退让，并输出对话；文字计划不自动路由。
原生放置仍要求实际接收盘接触、夹爪释放并持续稳定，不凭模型发话记成功。

## 设置与入口

两个任务：先准备接收盘、共享空间。task2/init0/seed0、cooperative、episode记忆、
20Hz、最多30秒；协调器每1秒推理、VLA/保持块最多10步。
本组合为Qwen3-VL-8B视觉协调器＋π0.5执行器，与Qwen3-14B人真实交互。
不能归为原始π0.5成绩。接口与执行器同时修正、机器人采样状态未配对，
不作单因素因果比较；只有一个布局和合成倾向。

```bash
bash scripts/run_native_libero_server.sh
bash scripts/run_robot_coordinator.sh
bash scripts/run_grounded_coordination.sh
```

启动前先检查nvidia-smi。协调模型GPU1、执行器GPU3、人和Sim GPU0；每程序单卡。
输出在数据盘`results/continuous_v2/grounded_coordination/<family>`，通过仓库软链接访问。
无本轮模型/数据下载；所有视频来自真实Sim运行，物体不吸附或控制期坐标写入。

独立审计继续重建模型控制、图像、消息、人的执行反馈、释放稳定与人物显示。
`verify_robot_coordination.py`本轮另外按实际控制日志重建self_execution；
`verify_native_libero_run.py`重建保持命令及它引用的上一条夹爪动作。
旧协调协议仍能审计，不为旧片段补写新观察或新得分。

```bash
python experiments/grounded_coordination_20261007/build_report.py
```

## 范围

这轮用于保证真实任务执行反馈可信，不把修正等同于人模型/机器人已经可靠协作。
原始分工依然固定，人体仍为非碰撞运动学显示和指尖受力代理，没有完整手部抓持。
成熟Benchmark还需真实操作、更多依赖/协商任务、开放目标、持续世界、多人格与统计协议。
报告分别展示实际执行次数、原始模型决定与物理结果，不把自己的计划当成完成事实。
