# 运行中改变人的工作要求：持续世界的动态HRC实测

[报告入口](index.html)。本批扩展真实原生任务，不再只观察固定分工的推盘/放碗。

## Material Passport

- 模式：run；材料：原生MuJoCo运行、π0.5真实动作、Qwen3-14B原始输入输出、真实Sim视频。
- 来源：本地中国源离线权重；参考：[COOPERA官方人类仿真说明](https://github.com/dannymcy/coopera_code/blob/main/HUMAN.md)。
- 研究问题：人在同一世界中收到新的工作要求，生成式人是否调整行为，现有具身模型能否继续有效协作？
- 状态：三条运行、视频及独立审计已完成；完整研究效度UNVERIFIED。

## 三类真实任务

|任务|公开要求变化|主要交互压力|
|---|---|---|
|receiver_changes|0秒盘到绿色；15秒改回蓝色原位；30秒再次到绿色|同一接收盘反复移动，旧放置位置失效，已完成关系可能被打破|
|priority_changes|0秒饼干到橙色；15秒改为盘到绿色；30秒饼干回紫色原位|不同物体的个人工作优先级改变，保留或放弃旧意图|
|interruption_return|0秒整理饼干；12秒临时事务要求暂离；18秒返回；30秒准备盘|动作中断、身体离返与当前世界衔接|

机器人公开任务始终是把桌面中央黑碗放到盘中。任务请求的时间预先声明，
人是否执行、等待、询问或改变计划由真实Qwen决定，不把要求转成预设动作序列。
这里只建立可复现的外部要求变化压力，尚不是完全由人自身长程意图产生的开放活动。
COOPERA用心理特征、长期意图驱动模拟人；本批参考这一组织方向，没有复用它的完整人类仿真或宣称同等效度。

## 世界与算法

每条45秒、20Hz，只初始化一次物理世界和人策略，保留真实物体位置、实际手/机器人状态、
生成目标、经验和公开历史。工作板更新不会重置这些内容，不因中途成功提前退出。
π0.5最多执行10步动作块，再看外相机、腕部相机和8维本体状态；公开语言含当前人工作和近期消息。
Qwen默认每2秒推理，有新公开要求时立即推理。推理时模拟时钟暂停，因此45秒不是实时运行时长。
这是π0.5加公开人工作上下文的系统配置，不是原始官方LIBERO排名。

绿色plate_ready/蓝色plate_home/橙色cookies_ready/紫色cookies_home都是实际场景标记。
目标从初始化时物体位置确定，要求改变时不移动物体或标记，只变更公开工作要求。
人的接触执行仍是力驱动指尖，显示身体不参与碰撞，只有推、观察、让行、暂离和返回。
机器人为真实学习模型7维末端增量动作，实际抓放与接触物理推进，没有吸附和教师接管。

## 测量与解释

- 新任务首个匹配动作延迟：模型首次选择当前对象/目的地或离返意图，只代表选择响应。
- 实际完成延迟：25mm目标范围、支撑高度误差25mm、低于0.08m/s稳定0.2秒，且本阶段有实际指尖接触。
- 阶段完成与末阶段保持完成分别记录，不把已取消或被破坏的旧任务计入最终共同成功。
- 暂离要求身体y≥0.80m且手y≥0.75m稳定0.2秒；返回要求此前确实暂离，身体y≤0.65m且手y≤0.70m。
- 旧/其他任务push次数描述未采纳当前工作要求的操作，不把observe/等待自动当作策略错误。
- 机器人完成按原生几何、盘碗接触、夹爪释放与持续稳定；双方最终完成才记共同完成。
- 接触采样、实际运动/同时运动/静止时间分开呈现，不合成未经验证的cobalance总分。

单布局、单seed、单合作倾向，无无变化匹配控制和跨人的统计，不能作因果提升、模型排名或真人泛化结论。
更多角色协商、完整手操作、场景/算法/人格多样性仍属完整目标未完成项。

```bash

  --input-dir results/continuous_v2/native_dynamic_activity \
  --output-dir /data1/sieniwgroup/sieniw/projects/HRC-Bench/datasets/native_dynamic_activity
```

帧stem为`<profile>__task02_init000_seed000__step000000`。同stem的`.png`、`_wrist.png`、
`.state.npy`、`.prompt.txt`、`.action.npy`、`.action_valid.npy`自动对应；没有配对manifest。
`NativeTrajectoryDataset`只返回公开模型输入和实际动作，不返回profile名、私有分数或成功标签。

这些是学习策略实际执行轨迹，不是专家目标；失败不会过滤成正向示范。
连续场景日志与视频保留为本地软链接，原场景网格仍依赖已有外部资产，未宣称可脱离资产独立部署。

## 已识别的初始化混杂

本批运行版本6f81583先发布旧默认推盘分工，再于0秒明确发布当前动态工作板。
