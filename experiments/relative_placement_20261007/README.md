[观看完整报告与真实Sim视频](index.html)。五段完整视频，另保留一段明确标记的不完整接口诊断。

## 目的与设置

上一批固定`bowl_home`不能表达“在当前接收碗上放置”。本轮提供`on:接收物`，从实际碰撞几何计算中央支撑位置，
根据已测抓持时的手／物体底面偏移设置放置，并在搬运和下降时跟随接收物。没有吸附、焊接或运行中物体坐标搬写。
该工具是接触支撑放置，不等于完整容器包含；暂不将相对工具目的地作为个人区域评分目标。

校准教师在同一原生厨房场景分别操作奶酪包、薄盘、酒瓶、黑碗：每条25秒／20Hz，机械臂原地。
校准不算生成式人策略、学习机器人或HRC成绩。薄盘下降到位阈值从10mm收紧至2mm。
奶酪修复后与模型实验运行源版本416c107；盘／瓶／碗源0877ad4；具体源哈希和运行中未变化证明各自保存。

模型实验是LIBERO_goal任务6／init0／seed0，40秒／20Hz；Qwen3-14B，independent倾向，episode记忆，每2秒决定；
真实π0.5外／腕RGB与8维本体、公开语言、最多10步OSC块。人的私有偏好不直接给机器人，只有公开话语传入。
没有预设人工作清单或定时目标更新，世界与人策略各初始化一次，推理时模拟时钟暂停。
人感知是理想几何与真实执行反馈，人物是VICO皮肤／骨骼显示，物理接触是双指手代理，非完整身体／五指动力学。

奶酪、盘最大抬升约12.64／13.02厘米；四条手峰速约0.196m/s、人物显示通过。
奶酪已物理放下但控制器未结束，不能将动作阶段结束、夹爪张开和物体释放混为一谈。
2/4物品在这一次校准条件下形成抓放见证，不代表普适操作库成功率。

模型实验80次真实π推理／800动作、人20次推理：原生奶酪关系10.50秒首次释放稳定，期末仍成立。
Qwen连续20次grasp奶酪；计划里提到`on:akita_black_bowl_1`，但实际相对place为0、人双指抬起见证为0。
人的个人目标一直为空、目标变化0、提案0，无目标参数错误；没有可评分个人目标，不能把它记作人的任务失败。
这是模型未按实际进展改换自己的动作，不是程序已执行它写的计划。机器人完成目标也不能证明双方理解或cobalance。

完整库存另发现酒瓶26.60秒低于桌面10厘米，最终落到地面附近，采样峰速4.89m/s。
跌落前有机械臂夹指接触见证，不能据此断言唯一因果；这是目标之外的实际物品损失。
目标物／手／人物运动核验通过不代表全部库存没有高速运动；自然跌落也不等于瞬移或控制器超速。
报告有直接定位该事件的视频按钮和`scene_integrity_verification.json`。原生任务成功不能掩盖持续活动的附带损失。

## 评分、核验与数据

多主体放置审计检查原生几何、实际接收支撑、双方手部全部无接触、两物体速度低于0.08m/s连续0.2秒。
旧规则额外要求机械臂空夹张开，错误排除了“人已放下、机器人在别处空夹闭合”。
本批保留旧分数，另写`multi_actor_release_verification.json`事后审计，不把分数输入策略。
未来新任务声明`require_robot_open_aperture=False`并严格排除所有手部接触；历史没有该字段的结果沿用旧协议重建。
校准时曾将机器人空夹设为闭合；未来校准恢复原地张开命令。原始运行和原分数不覆盖。

五段完整视频逐帧解码／时间轴通过：四条501帧／25.05秒，模型801帧／40.05秒，640×480／20fps。
模型输入像素、本体、原始动作、实际控制、20Hz时钟、人感知／命令、目标与公开边界、源冻结均独立核查。
π完整语言加状态最长83／200token，无截断。
CPU从保存XML与qpos/qvel重建mj_step最后积分前的几何缓存，相对坐标最大误差约1.4e-15m；
可用相对目的地随真实姿态变化为3／4个，核验按对象键匹配，未把不可穿过的中央竖线伪造为支撑。
校准选中碗的支撑位移仅约0.41mm；本批不能作为大幅移动容器放置的性能证据。

导出一条模型episode、80组双RGB／state／prompt、800个实际OSC动作，按同stem加载。
路径`datasets/relative_model_hrc`链接数据盘，失败与附带损失记录保留，教师不混入模型数据；不是专家示范。
无可评个人目标的joint_success为null，原始分数单独保留；辅助几何／释放／物品损失审计随episode链接。
