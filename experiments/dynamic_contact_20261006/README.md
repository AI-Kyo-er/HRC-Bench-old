# 动态人类与真实接触阶段报告

打开 [index.html](index.html)，可查看实验目的、三项任务的分工与评分、真实模型
与生成式伙伴结果、18段运行时 Sim 视频、96条实际示范数据，以及3000步新位置
专家训练和六条基本操作评测（0/6）。失败运行也保留完整视频。旧人体瞬移批次单独保存，当前接触手结果
仍受机器人基本操作失败与简化人体代理的限制；完整研究目标尚未完成。

`build_report.py` 读取数据盘软链接中的原始结果生成 HTML 与 `evidence.json`，
不会运行模型、仿真或改写评分：

```bash
python experiments/dynamic_contact_20261006/build_report.py
```

浏览器核查与截图独立生成；重建页面后需要重新核查。

重要运行必须先通过完整视频解码与时间轴核验，再进入正式报告。
`evidence.json` 记录结果来源哈希；模型操作成绩、教师示范和训练 loss 分开呈现。
