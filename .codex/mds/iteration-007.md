# 第七轮：使局部指导返回任务确实依赖历史

## 开始状态与范围

上一目标回合分类为有进展：40 次 14B 基础调用、六例真实仿真和四个既有检查点审计，分别定位了基础历史处理限制与 A/B 的成功率捷径。当前 HEAD `0f0f09d`，工作区初始干净；上一轮所有下载、模型和仿真实验已退出，没有需要重新启动的旧任务。

本轮先修复 B 的任务可辨识性，保持先仿真、后真机。A 的伙伴贡献和协调成本问题仍未解决，六类交互结构的整体目标保持；不能用一个修订后的 B 代替整个研究框架。未通过的 14B 全历史门槛保持，本轮暂不运行神经结构测试。

## 运行前设计要求

1. 增加独立的检查暂存位置，使 blue 的临时位置不再是外层目标的反面。外层目标 left/right 各自公开给出，且与 red/green 的目标、候选顺序、seed、其他物理条件独立。
2. 在同一 seed 与菜单条件内，两种外层目标应到达完全相同的真实检查状态及物理前缀。指导结束后 blue 仍在独立暂存区，red/green 进度相同，伙伴几何相同；接下来的有效 blue 放置目标则不同。
3. 全部变化在新的 v7 路径完成，不覆盖旧冻结。新增暂存技能与来源必须先通过真实摩擦抓放的低层验证，不使用运行时瞬移、固定 attachment 或直接赋值成功。
4. 模型可见候选相同且完整，不根据隐藏正确目标过滤；输入不含 case 名称、seed 或已归约的外层目标标签。原始公开约定历史本身应保留，这是被测信息而非泄漏。
5. 终止条件、拒绝与反馈分别记录。主指标关注获得目标纠错反馈前的首次有效放置选择；同时报告尚未选择放置、无进度动作、错误尝试和反馈后恢复。不能将试错后成功解释为未受帮助的历史恢复。
6. 规则参照只读取公开历史与真实物理观察。先记录其是否可完成、关键帧、全部 tick 接触与状态，再检验历史不敏感的固定目标/位置反推基线。

候选数量、暂存几何和开发 case 数由低层可行性检查后确定，在实际任务运行前冻结。目标方向与候选顺序独立变化，不复用上轮两者随 seed 一起翻转的设计。

只读可行性检查后确定开发方案：neutral 浅盘中心 `[0.65, 0, 0.005]`，blue 暂存目标 `[0.65, 0, 0.036]`；新增一个 `stage_blue_neutral` 动作，所有案例使用同一 22 候选菜单。几何间距只支持尝试，不代表 IK 或接触验收已通过。

实际顺序为 red 入固定 left → 进入 blue 局部指导 → blue 暂存 neutral → 伙伴占位检查 → yield 让伙伴实际撤离 → green 在 child 活动期间入固定 right → finish → blue 返回外层 left/right。green 不提前在 child 外完成，以真实覆盖局部指导期间的其他进度及退出后的保留。

先运行 neutral→left/right × direct/careful 四个新控制，包含同样的真实伙伴进退与非目标物品保留。通过后冻结 blue 外层目标 left/right × seed60/61 × 菜单 normal/reverse 的八个规则参考。暂存、green 进度和返回目标的判断全部基于真实物理状态。partner 占位时从 neutral 取物不是这四例的能力承诺；本协议要求先实际退让再取物。

## 如何验收测量有效性

检查点相同只解决当前几何差异，不自动证明历史必要。需要同时验证两种历史对应的有效放置目标集合不相交，并排除其他输入字段编码目标。共同合法的让行或请求等无进度动作不应被人为禁止，但不能帮助无历史策略获得无反馈的正确目标。

在平衡的目标配对中，若无历史策略看到的其余输入完全一致，且在首次放置前没有额外目标信息，那么固定目标策略至多命中每对之一。这是构造的信息条件，不是模型缺陷或新理论发现。若反馈显露目标，后续成功必须另算；若当前几何或其他物品目标又能反推答案，则设计仍未通过验收。

返回点重新明确目标的参照可以匹配物理操作，但它提供了额外信息支持，不能称严格等信息的因果对照。其用途是区分“知道当前目标能否执行”和“是否能从历史恢复目标”。将来要研究交互组合，还需独立的组成能力、操作匹配与结构留出，而不是仅比较长历史和短提示。

## 当前覆盖与剩余研究要求

| 结构 | 当前证据 | 仍缺少的关键证据 |
| --- | --- | --- |
| 接力式转换 | 脚本约定可跨阶段持续 | 有效约定与真实伙伴贡献的接续 |
| 局部嵌套 | v5 单层 scope 可执行，已发现位置反推捷径 | 本轮修订后的辨识性；后续组合与新结构测试 |
| 同时叠加 | 占位与指导可在同一场景出现 | 多种要求的相互影响及匹配参照 |
| 历史赋义 | A 约定义务不同，但统一策略仍全成功 | 能区分理解的必要行为或有依据的实际协作成本 |
| 双向诱发 | 早期协议有请求/回应；v5 请求分支未暴露 | 接受、修改、拒绝造成的真实后续关系变化 |
| 暂离与重返 | 尚无对应的持续任务验收 | 期间自主推进、失效分工更新与重返衔接 |

当前伙伴仍是运动占位及检查脚本代理，尚无真人协调成本证据；语言高层策略加固定技能也不等于端到端 VLA。修复本轮测量漏洞是后续研究的必要条件，不是论文贡献已经成立。
