# 研究证据状态与完成边界

本表用于防止把某轮小实验完成误当作整体研究目标完成。更新至第十二轮模型诊断与独立审计。原目标仍是持续共同活动中的交互结构组合与演化，不缩减为一个约定解析器。

| 原研究要求 | 当前直接证据 | 尚未达到的范围 |
|---|---|---|
| 接力式转换 | v8 有真实载台投递及机器人接手 | 跨阶段指导如何约束共同执行，及多种接力关系的泛化 |
| 协作中的局部嵌套 | v7 有临时检查及外层恢复；v11 有 child 期间 outer 更新，真实规则轨迹通过 | 多层/不同物品作用域、结构留出、神经闭环和恢复 |
| 多种作用同时叠加 | v8 有运输与独立整理实际重叠 | 指导、互补操作与干预约束的联合测试，不仅普通并行调度 |
| 同一行为因历史而改变意义 | v7 同物理检查点对应不同外层目标；v11 接受/拒绝改变有效返回目标 | 同一伙伴物理行为的不同交互意义及其行动后果 |
| 机器人主动引发关系变化 | 旧接口包含 request/回应协议，部分早期规则轨迹有调用 | 当前新结构中的自主提出、接受/修改/拒绝与伙伴实际行为闭环 |
| 暂离与重返中的连续性 | 保留公共进度/历史的基础可用 | 明确的暂离、期间独立推进和重返重新衔接对照 |
| 局部能力与组合差距分开 | 低层抓放控制有覆盖；v9 局部 stage/yield/finish 输出可用 | 完整组成能力覆盖；旧 14B 全历史门槛仍未过，不能换标准宣称通过 |
| 长度和操作难度对照 | v11 最终检查点事件、字符/token、预算匹配，机械轨迹匹配 | 全过程输入并不匹配；顺序与新近程度一起变化，未排除一般状态更新解释 |
| 未见组合 | 尚无直接证据 | 场景 seed、菜单反序和左右反平衡均不等于结构留出 |
| 真实协调后果 | v8 规则策略有 13.25 秒模拟共同完成时间差 | 模型真实闭环代价；推理延迟、响应型伙伴及真人体验均未验证 |
| 模型可复现与故障分类 | 本地固定版本、逐条输出、输入配对/物理审计、失败保留 | 多个较强模型与表达变化下的稳健结论；单个小集错误不能证明一般能力缺口 |
| 理论与新颖性 | 已核验 HRI/协作、约定管理、状态追踪与组合评测相关工作 | 不把已有概念重命名为贡献；尚缺足以支持独立论文主张的受控实证 |
| 外部有效性 | 用户已确定先仿真、后真机 | 机械代理不等于真人；真机和人类伙伴验证尚未开展 |

当前阶段是机制与测量原型。第九/十轮已经说明，仅有“历史输入错误、显式辅助有效”不足以定位交互结构机制；第十一轮构造了识别约定回滚的物理匹配对照。第十二轮全条件模型诊断未在结束后观察到指导期间更新更难的计数结果；错误投递全部跟随被拒绝的提议，与人为旧快照策略的失败条件不同。结束前有期间更新条件下提前执行外层动作的现象，但新近程度与显式结束接口仍可能解释它，尚未证明神经模型存在所假设的约定回滚机制。

后续应优先获得能改变研究判断的证据，而不是不断增加同模板调用：保留完整条件的结构比较；检查表达与一般状态更新的替代解释；将确认的依赖连接到伙伴响应和实际任务后果；再建立明确的结构划分。简单正确的公开账本、规则策略和模块化方法始终允许参与比较，不通过排除它们来制造难度。

任何最终论文定位都应随负结果修订。当前不能标记整体目标完成；可审计的贡献主张必须由相应范围的证据支持。
