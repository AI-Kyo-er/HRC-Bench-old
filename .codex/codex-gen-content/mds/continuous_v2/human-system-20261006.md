## 本轮实际实现

- `articulated_contact_hand`：XYZ、腕部 yaw、双指六个受控自由度。物体受重力、
  碰撞、摩擦作用，停止调用 Avatar 对物体的直接坐标写入。Runtime 检查机器人 /
  Avatar 都没有 attachment。接触手和显示人物是代理，不是完整人体动力学。
- 人物沿工作台外边界限速移动，使用已有步行动作和躯干 IK 跟随实际手；排除
  人体粗碰撞盒与自身手的碰撞。身体 / 物体碰撞未作真实人体安全效度验证。
- 生成式观察、离返、暂停可改变正在进行的动作；释放 / 退让时队列保存最新
  意图，完成机械清离后再执行。物体移动后重新定位，夹持方向与最低桌面净空
  随实际物体姿态调整。这些是动作原语，不选择人类任务或分工。
- 原生 OpenPI 入口默认真实摩擦接触。Qwen 获得实际手的位置和当前可见动作阶段，
  仍只读取公开信息；机器人仅有双相机、本体状态和公开语言五键输入。
- Dataset 采集和加载接口：输入 stem 匹配 `_wrist.png`、`.state.npy`、
  `.action.npy`，动作监督来自实际下一物理步的关节变化，非大幅 IK 请求跳变。
  不生成配对 manifest，15×8 动作块带有效时段标记；失败保留视频，不生成有效目标。
